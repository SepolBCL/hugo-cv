# Hugo Filipe Ferreira Lopes | Interactive CV Website

Professional React + Vite CV website featuring:

- Recruiter-focused executive presentation
- Bilingual interface: English and Portuguese
- Section-based profile navigation
- Professional portrait integration
- Downloadable PDF CV
- LinkedIn and GitHub integration

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion

## Setup

1. Install dependencies

```powershell
npm.cmd install
```

2. Start development

```powershell
npm.cmd run dev
```

3. Build for production

```powershell
npm.cmd run build
```
